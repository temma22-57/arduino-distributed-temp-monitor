# Distributed Arduino Temperature Monitor

A temperature monitoring system using multiple arduinos.
Arduinos designed to be power-aware.
Custom binary serial protocol.
Nodes support periodic and on-demand reporting.
Nodes have persistent EEPROM-backed configuration.

Windows based Python CLI/GUI aggregates and logs sensor data.
